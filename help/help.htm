LPGallery plugin: Install and file & folder permissions

Installing the plugin

  1. Unzip LPGallery.zip on your computer. Copy the LPGallery folder into the plugins folder of your CMSimple_XH installation (plugins/LPGallery/).
  2. Make sure the files sit directly in plugins/LPGallery/, not in an extra subfolder inside it.
  3. Create userfiles/gallery/ and set the permissions described below.

Assumed paths: CMSimple_XH is in /var/www/html, and the site owner account is youruser. Adjust these if yours differ.

How permissions work

The web server user (www-data on Ubuntu/Debian) needs write access to userfiles/gallery/. You create userfiles/gallery/ once manually. Everything inside it—such as gallery folders like test/, their thumb/ subfolders, thumbnails (tn_*.jpg), and comment/metadata .txt files—is created automatically when a page containing {{{LPGallery('userfiles/gallery/test')}}} is opened.

userfiles/gallery/ is set to 2775. The 2 is the setgid bit: anything created inside it automatically gets the group www-data, including new gallery folders. Thumbnails and .txt files created by the plugin are saved with mode 664, so the group can edit them too. Keep 2775 on userfiles/gallery/; if changed, new folders may not inherit the right group.

Photos you copy in yourself (for example via FTP/SFTP) keep the permissions your client gives them. Reading and scaling them works as long as they are world-readable (644).

If you want to edit .txt metadata files or manage gallery folders yourself without sudo, add your account to the www-data group (see the commands below) and log in again.

userfiles/ itself stays read-only (755) for the web server.

Note on POSIX ACLs (+ in ls -ld): If ls -ld shows a + sign at the end of the permissions (e.g., drwxrwsr-x+), an active POSIX Access Control List may override the group permissions and still block www-data from writing. Run sudo setfacl -b -R on userfiles/gallery and plugins/LPGallery/config before applying chmod (included in the commands below).

Folders and files

PathOwner / groupPermissionsWhy
userfiles/youruser / www-data755Read only. The web server does not need to write here.
userfiles/gallery/youruser / www-data2775Created by you once. LPGallery automatically creates gallery folders, thumbnails, and .txt files inside it.
plugins/LPGallery/ (PHP files & help/)youruser / www-datafolders 755, files 644The web server only needs to read these.
plugins/LPGallery/config/youruser / www-data2775CMSimple_XH saves config.php here when you update plugin settings.
plugins/LPGallery/config/config.phpyouruser / www-data664Settings saved from Plugins > LPGallery > Settings.

Never use 777. The 2 in 2775 ensures all newly created folders and files stay in the www-data group.

LPGallery inherits your website template's stylesheet automatically, so no plugin CSS folder or extra permissions are needed.

Commands

Run these on the server with sudo. Adjust the variables at the top first if needed.

CMS=/var/www/html
OWNER=youruser
WEB=www-data
PLUGIN=$CMS/plugins/LPGallery

# create the top gallery folder once manually (and strip any blocking ACLs)
sudo mkdir -p $CMS/userfiles/gallery
sudo setfacl -b -R $CMS/userfiles/gallery
sudo chown -R $OWNER:$WEB $CMS/userfiles/gallery
sudo chmod 2775 $CMS/userfiles/gallery

# userfiles itself stays read-only for the web server
sudo chown $OWNER:$WEB $CMS/userfiles
sudo chmod 755 $CMS/userfiles

# plugin code: read-only for the web server
sudo setfacl -b -R $PLUGIN
sudo chown -R $OWNER:$WEB $PLUGIN
sudo find $PLUGIN -type d -exec chmod 755 {} +
sudo find $PLUGIN -type f -exec chmod 644 {} +

# plugin config folder that CMSimple_XH admin writes to
sudo chmod 2775 $PLUGIN/config
sudo chmod 664 $PLUGIN/config/config.php

# optional: let your account edit gallery files without sudo, then log in again
sudo usermod -aG $WEB $OWNER

To verify the permissions afterward:

ls -ld $CMS/userfiles $CMS/userfiles/gallery $PLUGIN/config

Creating your first gallery

  1. Create a new page in CMSimple_XH and add {{{LPGallery('userfiles/gallery/test')}}} (or any other folder name inside userfiles/gallery/) to its content.
  2. Open the page in your browser. LPGallery automatically creates userfiles/gallery/test/ and its thumb/ subfolder.
  3. Copy your photos (JPEG files) into userfiles/gallery/test/, for example with FTP/SFTP.
  4. Reload the page. Thumbnails (thumb/tn_*.jpg) and a matching .txt file for each photo are created automatically.
  5. Open a photo's .txt file to edit its title, description, or extra fields:
    • Line 1: Holds the title (underscores are shown as spaces), optionally followed by extra fields separated by semicolons (;), which are displayed below the photo. Configure the labels for these extra fields under Plugins > LPGallery > Settings (extra_info_labels).
    • Lines without ;: Form a longer description shown together with the title (above or below the photo depending on title_placement in Settings).
    • Lines with ;: Visitor comments stored in the format DD-MM-YYYY HH:MM;Name;Comment; and shown below the photo.
