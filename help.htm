LPGallery plugin: installation, permissions and photo files

Installing the plugin

  1. Unzip LPGallery.zip on your computer. Copy the LPGallery folder into the plugins folder of your CMSimple_XH installation, so that the files end up in plugins/LPGallery/.
  2. Make sure the files sit directly in plugins/LPGallery/, not in an extra subfolder inside it.
  3. Create userfiles/gallery/ and set the permissions described below.
  4. Create a page and add the page tag in the form below. The tag is written with HTML entities so that the server's security filter does not block the page: 
    &#123;&#123;&#123;LPGallery('userfiles/gallery/test')&#125;&#125;&#125;
    Open the page. LPGallery creates userfiles/gallery/test/ and its _thumbs/ subfolder, and a .json file for each photo.

Assumed paths: CMSimple_XH is in /var/www/html, and the site owner account is youruser. Adjust these if yours differ.

How permissions work

The web server user (www-data on Ubuntu/Debian) needs write access to userfiles/gallery/. You create userfiles/gallery/ once. Everything LPGallery creates below it (gallery folders such as test/, their _thumbs/ subfolders, thumbnails and .json files) is created automatically when a page with the gallery tag is opened.

userfiles/gallery/ is set to 2775. The 2 is the setgid bit: anything created inside it gets the group www-data, including new gallery folders. Files created by the plugin are written with mode 664, so the group can edit them too. Keep 2775 on userfiles/gallery/; if it changes, new folders may not get the right group.

Photos you copy in yourself (for example by FTP or SFTP) keep the permissions your client gives them. Reading and scaling them works as long as they are world-readable (644).

If you want to edit the .json files or manage gallery folders yourself without sudo, add your account to the www-data group (see the commands below) and log in again.

userfiles/ itself stays read-only (755) for the web server.

POSIX ACLs (+ in ls -ld): if ls -ld shows a + after the permissions (for example drwxrwsr-x+), an access control list may override the group permissions and block www-data from writing. The commands below remove these lists first.

Folders and files

PathOwner / groupPermissionsWhy
userfiles/youruser / www-data755Read only. The web server does not need to write here.

Never use 777. The 2 in 2775 makes sure new folders and files stay in the www-data group.

LPGallery uses the stylesheet of your website template, so no plugin CSS folder or extra permissions are needed.

Commands

Run these on the server with sudo. Change the variables at the top first if needed.

CMS=/var/www/html
OWNER=youruser
WEB=www-data
PLUGIN=$CMS/plugins/LPGallery

# create the gallery folder once and remove blocking ACLs
sudo mkdir -p $CMS/userfiles/gallery
sudo setfacl -b -R $CMS/userfiles/gallery
sudo chown -R $OWNER:$WEB $CMS/userfiles/gallery
sudo chmod 2775 $CMS/userfiles/gallery

# userfiles itself stays read-only for the web server
sudo chown $OWNER:$WEB $CMS/userfiles
sudo chmod 755 $CMS/userfiles

# plugin code: read-only for the web server
sudo setfacl -b -R $PLUGIN
sudo chown -R $OWNER:$WEB $PLUGIN
sudo find $PLUGIN -type d -exec chmod 755 {} +
sudo find $PLUGIN -type f -exec chmod 644 {} +

# plugin config folder that CMSimple_XH writes to when settings are saved
sudo chmod 2775 $PLUGIN/config
sudo chmod 664 $PLUGIN/config/config.php

# optional: let your account edit gallery files without sudo, then log in again
sudo usermod -aG $WEB $OWNER

To check the permissions afterwards:

ls -ld $CMS/userfiles $CMS/userfiles/gallery $PLUGIN/config

Adding pictures

  1. Copy JPEG files (.jpg or .jpeg) into userfiles/gallery/test/, for example with FTP or SFTP.
  2. Reload the page. LPGallery creates a thumbnail in _thumbs/ and a .json file for each photo, with the same name as the photo.
  3. Open the .json file to add a title, description, metadata or comments (see below).

The .json file for each photo

For a photo called sunset.jpg, LPGallery uses sunset.json. The file is created automatically with an empty description, the metadata fields from the setting meta_default_keys, and no comments:

{
    "title": "sunset",
    "description": "",
    "meta": {
        "Camera": "",
        "Location": "",
        "Date": ""
    },
    "comments": []
}
  • title: the title shown above or below the photo. The file name is used when it is empty. Underscores and hyphens are shown as spaces.
  • description: a longer text. Line breaks are kept.
  • meta: pairs of label and value. Empty values are not shown. Add labels of your own if you want more fields.
  • comments: added by visitors with the Add a comment link. Each comment has a date, an author and a message. Visitors' comments are saved to this file, so do not delete the list.

Keep the file valid JSON: put text between double quotes, use a comma between items and no comma after the last item. Use a JSON checker if the photo's information does not appear after an edit. A broken file is ignored, so the title and comments disappear until the file is repaired.

Settings

Open Plugins > LPGallery > Settings in the CMSimple_XH administration. The settings are saved in plugins/LPGallery/config/config.php.

SettingMeaning
Grid columns, grid rowsThumbnails per page (rows x columns).
Show captions, caption positionShow the title and description in the thumbnail view and the large view, above or below the picture.
Thumbnail size, JPEG quality, square cropLargest side of the thumbnails in pixels, JPEG quality (10 to 100) and whether thumbnails are cropped to a square.
Large picture size, JPEG qualityLargest side of the large picture in pixels and its JPEG quality.
Watermark text, size, padding, vertical and horizontal position, colourThe watermark is drawn on the large picture only. Size 1 is the smallest and 5 the largest. The colour is a hex value such as #ffffff. Leave the text empty for no watermark.
Show metadata, default metadata keysShow the meta fields from the .json file. The default keys are added to new .json files, separated by commas.
Enable comments, spam checkShow the comments and the Add a comment link. The spam check asks a simple sum before a comment is saved.

Watermark font

If the server has TrueType fonts (for example DejaVu Sans), LPGallery uses them, and the watermark can contain any character, including the copyright sign. Without one, a bitmap font is used. To use your own font, put a file named font.ttf in plugins/LPGallery/.

Troubleshooting

  • The folder is not writable by the web server: check the permissions of userfiles/gallery above.
  • Could not save file ./plugins/LPGallery/config/config.php: check the permissions of the config folder and file above.
  • A 403 Forbidden page when you save the page: the server's security filter (ModSecurity) has blocked the text. Use the HTML entity form of the page tag shown above.
  • No thumbnails: check that the photos are JPEG files and that the page loads without an error message.
